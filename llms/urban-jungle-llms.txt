# Urban Jungle

> Urban Jungle Services Ltd is a London-based direct-to-consumer insurtech founded in 2016 by Jimmy Williams and Greg Smyth, selling home, contents, students contents, tenants liability, landlord, home emergency and public liability cover to UK renters and sharers at myurbanjungle.com. It is FCA-authorised (FRN 782061), registered in England and Wales (company number 10414152) and a certified B Corp. Urban Jungle operates a partner quote API, announced in 2018, but that API is entirely partner-gated: there is no developer portal, no reference documentation, no machine-readable specification, no published authentication scheme and no self-serve signup.

## Machine-readable contracts

Urban Jungle publishes none. As of 2026-07-25 no OpenAPI, Swagger, AsyncAPI, GraphQL SDL, .proto, Postman collection or webhook catalog exists in public, and no /.well-known/ document is served on any Urban Jungle host. Do not attempt to guess endpoints: the only host that answers, https://api.myurbanjungle.com, returns a two-byte "OK" body and hard-404s every specification path, and https://myurbanjungle.com is an Angular single-page app that soft-404s (HTTP 200 plus an identical HTML shell for every path, including bogus ones), so a 200 from it is never evidence a resource exists.

## How to integrate

- Partnership programme: https://myurbanjungle.com/partners
- Affiliate programme: https://hello.myurbanjungle.com/partner-with-us/
- The only documented route to API access is emailing partnerships@myurbanjungle.com. Three integration models are offered: Simple Referral (a unique referral link), API Integration ("Give customers a personalised quote, on your site or app", with sample code supplied privately to partners), and a journey wrap. Target partners are letting agents, PropTech companies, institutional landlords, eCommerce sites and financial services firms; the design intent is that a partner can serve Urban Jungle quotes without being directly FCA-regulated.
